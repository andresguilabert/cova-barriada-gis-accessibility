\# Palaeolandscape Accessibility Analysis



This project develops a \*\*parameterised and reproducible ArcGIS Pro Notebook workflow\*\* to investigate the potential accessibility of the palaeocoast from Cova de la Barriada, an archaeological site in Serra Gelada, Benidorm, Spain.



\## Workflow and Map Outputs



The workflow generates least-cost routes, travel-time isochrones and coastal accessibility zones from terrain and bathymetric data. The maps below illustrate how changing analysis parameters affects the resulting outputs.



!\[Palaeocoast accessibility analysis — alternative map configurations](FIGURES/palaeocoast\_accessibility.gif)



\## Tools and Methods



\- ArcGIS Pro and ArcPy

\- Digital terrain model generation

\- Distance accumulation and optimal path analysis

\- Tobler's hiking function for slope-dependent walking speeds

\- Travel-time isochrones and coastal accessibility zonation

\- Automated map production and export



\## Repository Contents



\- `Cova\_Barriada\_Least\_Cost\_Analysis.ipynb` — main analysis workflow

\- `figures/` — project figures and animated map outputs



\## Reproducibility



The workflow is parameterised to facilitate rerunning the analysis with alternative inputs and settings. It is designed to generate the principal analytical outputs and map products within ArcGIS Pro.
